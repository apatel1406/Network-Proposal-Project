# Network Proposal Project Summary 

## Techopoly Inc.  

Our approach to this network has been unique. With key aspects such as security, reliability, and performance being kept in mind with the whole network design. This network has been designed to be expanded and still have the same level of security and reliability. With a multilayered user diagram and a comprehensive network diagram, our network has been laid out in an easy-to-understand fashion.  

We have prioritized a changeable design to support changes in the future and adding or switching new components without compromising functionality. Each network component, from the switches to the layout of the whole system, was carefully selected to balance cost-efficiency with high availability (so that all devices are connected to the internet).  

Security is one of our 3 key aspects, in this network, security has been taken very seriously. With the implementation of a state-of-the-art controllable firewall and a well-faceted hierarchical user diagram, we have made sure that not just the network is secure, but all the data that will be stored on our 3 servers will also be access controlled. This was made possible by our network tree, which makes it clear which groups and users will have access to certain tools and data. Yes, all personnel have access to all 3 servers, but data will only be accessible if that individual or group has the correct permission to access that piece of data.  

Reliability is also a key aspect of our network, with our network design being reliable and sustainable. Reliable in the sense that everyone will have access to a wired internet connection regardless of position, and since our servers are connected to the internet, anyone can connect to their work PC and gain access to these servers wherever they are in the world. Our IT team can also control aspects of VLAN distribution via the UniFi 40-port switch, allowing separations of the entire network.   

Performance was our last and final aspect of our network. The network has been designed in a way that allows for expansion into 5 more devices and has the ability to add more switches, expanding the current 40 ports. Even with all 30 PCs, 5 printers, and 3 servers, our network is still able to produce high speeds and allows us to give our employees access to data whenever they need it and allows remote printing.
